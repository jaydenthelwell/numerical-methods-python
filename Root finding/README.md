# Root Finding in Python

A small project exploring numerical methods for finding roots of functions, based on topics covered in my undergraduate physics coursework.

### What I explored

- **Bisection:** Repeatedly halves an interval to narrow down a root.
- **Regula falsi:** Uses a straight line between two points to estimate a root.
- **Comparing methods:** Testing both methods on different functions and comparing their convergence.

The script also plots a test function to show where its roots are.

### Tools

- Python
- NumPy
- Matplotlib

### Running the code

Install the required libraries:

```bash
python -m pip install numpy matplotlib
```

From the repository's main folder, run:

```bash
python "Root Finding/root_finding.py"
```

### What I'm learning

This project is helping me understand how numerical root-finding methods work, how their convergence differs, and why choosing an appropriate interval matters.
